# FinalFit3D Claude Code Rules

This is a Unity 3D anime-inspired fashion battle game.

Never create an HTML mockup unless explicitly asked.
Never create a flat 2D-only game.
Never make stick-figure characters.
Never make clothing only appear as UI cards.
The game must be a walkable 3D prototype.

## Safety / style
All avatars are adult.
Anime-inspired but original — no copyrighted anime character copies.
Fashion-focused: drip, silhouettes, runway presentation, competition.
Stylized proportions are fine; keep everything game-appropriate.

## Technical
Use C#.
Use Unity scenes (generated by Assets/Editor/FinalFitSetup.cs).
Use prefab-style builders (procedural until real assets are imported).
ClothingItem and RoundTheme are ScriptableObjects.
Keep the game runnable after every step.
Fix compile errors before adding new features.
All scene content is constructed at runtime by the SceneBuilders — scenes
contain only a Bootstrap object. This is intentional: it lets Claude Code
iterate on the whole game in plain C# without binary scene merges.

## Architecture map
- Core/        GameManager (persistent state), SceneLoader, MaterialFactory, UIFactory
- Avatar/      AvatarBuilder (procedural rig), AvatarRig, presets/body config,
               SimpleWalkAnimator, AvatarEquipmentManager
- Clothing/    ClothingItem (SO), ClothingDatabase, ClothingMeshFactory (visible drip)
- Player/      ThirdPersonController, CameraController
- Store/       ClothingRack, StoreInteraction, StoreUI
- NPC/         NPCShopper (ambient AI), RunwayPreviewDirector (judges + struts)
- SceneBuilders/ one builder per scene + SceneKit helpers
- Future/      RoundTimer, RoundTheme, JudgeScoringSystem scaffolds (phase 2)

## Replacing placeholders with real anime models (later)
Everything talks to AvatarRig + AvatarEquipmentManager, never to primitives.
Swap AvatarBuilder.Build to instantiate a rigged model, map its bones onto the
AvatarRig fields, convert BodyConfig to blendshape weights, and point
ClothingMeshFactory at real clothing prefabs keyed by MeshStyle.
